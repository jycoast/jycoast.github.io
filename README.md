# 关于项目

这是一个个人技术知识库，用来记录和整理学习内容。

站点主题覆盖 Java、数据库、框架、中间件、计算机原理、算法与学习路线等内容。

## 本地运行

安装依赖：

```shell
npm install
```

启动开发服务器：

```shell
npm run docs:dev
```

构建生产版本：

```shell
npm run docs:build
```
